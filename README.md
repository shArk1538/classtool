# 📦 长方体纸盒剪开 · 展开图动态演示课件

小学数学三年级上册「长方体纸盒剪开」课堂演示工具。3D 动态演示：剪开 7 条棱 → 面顺势摊开 → 得到展开图。

**✨ 零依赖 · 双击即用 · 完全离线** —— 无需安装 Python、无需启动服务器、无需联网，老师把文件夹拷到 U 盘插到教室电脑双击就能上课。

---

## 一、快速启动（推荐给老师）

### 🥇 方式 A：双击即用（最简单，零依赖）

**直接双击 `cuboid-net.html`**，浏览器自动打开，看到 3D 纸盒即成功。

- ✅ 无需安装任何软件
- ✅ 无需启动服务器
- ✅ 完全离线运行
- ✅ 支持 Windows / macOS / Linux
- ✅ 可拷到 U 盘、发到微信群、上传到希沃白板

> 💡 **首次打开提示**：某些浏览器可能提示"是否允许此网页访问文件"，选择"允许"即可。

### 🥈 方式 B：命令行启动（备用）

如果方式 A 因浏览器安全策略受限，可用此方式：

```bash
# 在本文件夹下打开终端，执行：
python3 -m http.server 8000
```

然后浏览器访问：**http://localhost:8000/cuboid-net.html**

（Windows 上命令可能是 `python -m http.server 8000`）

### 🥉 方式 C：VS Code / Trae 用户

安装 "Live Server" 类插件，右键 `cuboid-net.html` → Open with Live Server。

## 三、课堂操作速查

### 顶部三个模式

| 模式 | 用法 |
|---|---|
| ✂️ 剪棱 | 点击**发光的蓝色棱**，小剪刀光点沿棱划过后剪开；能展开的面会顺势自动摊开。橙色是折痕，剪了面会掉（程序会阻止并提示） |
| 🖐 展开/折叠 | 点击某个面，沿折痕摊开 / 折回 |
| 🔢 数棱 | 点击棱打数字标记，带学生一起数 12 条棱 |

### 右侧边栏

- **🎬 预设展开方案**：十字形 / 一字形 / 阶梯形，自动慢速（0.5x）演示"剪 7 条棱 → 逐步摊开"全过程：每一刀前镜头自动聚焦到棱上，小剪刀光点划过后剪断，适合课堂放映（演示期间鼠标操作会暂时锁定，结束后自动恢复）
- **一键展开 / 一键折起**：快速切换形态
- **↩ 撤销 / ⟲ 重置**：退回一步 / 还原完整纸盒（撤销也支持快捷键 `Ctrl/⌘ + Z`）
- **进度条**：实时显示"已剪 x/7"，剪满 7 条自动判断剪法是否正确
- **显示开关**：面名称（上/底/前/后/左/右，相对面同色，字号自动保持清晰、不随面大小变化）、自动旋转、音效
- **📐 纸盒尺寸**：长 / 宽 / 高三条拉杆（1~10）实时换纸盒，三值相等即正方体

### 鼠标操作

- **左键拖拽**：旋转视角（始终围绕图形几何中心）
- **右键拖拽**：平移视角
- **滚轮**：缩放

### ❓ 帮助按钮

顶栏 ❓ 可随时打开内置图文说明（学生也能看懂）。

## 四、常见问题

| 问题 | 解决 |
|---|---|
| 双击 html 页面空白 | 极少数浏览器安全策略较严，改用"方式 B"命令行启动 |
| 页面异常或按钮无反应 | 可能缓存了旧版本，硬刷新一次：Windows `Ctrl+Shift+R`，Mac `Cmd+Shift+R` |
| 提示端口 8000 被占用 | 把启动命令里的 `8000` 换成别的端口（如 `8080`），浏览器地址同步改 |
| Windows 提示找不到 python | 未安装 Python 或未加入 PATH，可改用"方式 A"双击即用 |
| 没有网络能上课吗 | 可以，课件完全离线运行 |
| 触屏能用吗 | 可以，单指拖动旋转、双指缩放、点按棱/面均支持 |
| 希沃白板能用吗 | 可以，把文件夹拷到希沃电脑，双击 `cuboid-net.html` 即可 |

## 五、技术说明

- **零依赖**：单文件网页（HTML + Three.js UMD 版），无需安装任何依赖
- **完全离线**：Three.js 已内置在 vendor 目录，无需联网
- **双击即用**：传统 script 标签加载，支持 file:// 协议，双击 HTML 即可运行
- **跨平台**：现代浏览器（Chrome / Edge / Safari / Firefox）均可运行
- **易分发**：整个文件夹打包即可分享，无需考虑环境配置

*改造说明：原 ES Module 版本需 HTTP 服务器才能运行，已改为 UMD 版本实现真正的零依赖双击即用。*
